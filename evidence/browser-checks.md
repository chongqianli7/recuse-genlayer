# Browser checks

The public GitHub Pages application was opened and its Live on GenLayer → Read published example path verified the deployed source and loaded the finalized PASSED record without a wallet. The JSON export was downloaded and checked for CHAIN_READBACK, the configured contract, two eligible members and PASSED. `browser-readback.json` is this export; its null receipt means a state read, not a newly signed transaction. `browser-live.jpg` shows the resulting screen.

The worked example was also operated through one YES vote (not yet decisive), a second YES vote (decisive), and finalization to PASSED. A 390-pixel iframe viewport showed a readable mobile landing layout with stacked sections. Mobile wallet interactions and extension-wallet signing were not tested. Real chain writes in the network evidence used SDK-signed test accounts.
